# 📰 Fake News Detection System

## 🔍 Overview

This project detects whether a news article is Fake or Real using Machine Learning.

## 🛠 Technologies Used

* Python
* Scikit-learn
* TF-IDF Vectorization
* Naive Bayes
* Streamlit

## ⚙️ Features

* User can input news text
* Real-time prediction
* Shows confidence percentage
* Simple and clean UI

## 🧠 How it Works

1. Text is cleaned and preprocessed
2. TF-IDF converts text into numerical features
3. Naive Bayes model predicts Fake or Real
4. Streamlit displays the result

## ▶️ How to Run

1. Train model:
   python text_model.py

2. Run app:
   py -m streamlit run app.py

## 📊 Result

Achieved high accuracy (~95%) on dataset

## 📌 Conclusion

Fake news detection requires good data and proper text processing.
Naive Bayes works effectively for text classification problems.
